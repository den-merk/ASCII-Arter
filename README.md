# ASCII-Arter
> ASCII Arter? - Yes🎨

Hello! This is my **Python** program that transforms any regular image into cool **ASCII art** and kind of **pixel art**. 

I wanted to create a tool that allows you to look at familiar images and photos in a new way, converting them into a text format while preserving details or color.

> ⚠️ **Important Note:** Currently, this program only works and has been tested on **Windows 10**. Support for other operating systems (Linux/macOS) is not yet available.

### 🌟 Features:
* **Classic ASCII Art** — converts images into characters of varying density (text-based graphics).
* **Colored ASCII Art** — prints character-based images directly into the console while keeping the original colors.
* **Pixel Art** — turns images into colored block pixels for a retro effect.
* **Export to File** — saves the resulting text art into a regular `.txt` file so you can easily share it.

---

### 📋 Prerequisites

To run this program, you will need **Python 3.x** and a few libraries for handling graphics and terminal colors.

Install the dependencies with a single command in your terminal:
```bash
pip install Pillow rich
```

To get started, simply run `main.py`

## 📂 Project Structure

Here is what you will find inside the project folder:

* **`main.py`** — The main script to run the application.
* **`pol.txt`** — A customizable text file containing the color palette (character gradient) used to generate the ASCII art. You can edit this file to change how contrast and shading are rendered.
* **`example.jpg`** — A sample image you can use to test the generator right away.
* **`example.txt`** — An example of the exported text-based ASCII art generated from the sample image.
* Other project files whose purposes are self-explanatory by their names.
